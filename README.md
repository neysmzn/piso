# piso

Panel web sencillo para gestionar actualizaciones de estado de un producto.

## Funcionalidades
- Alta de actualizaciones con producto, estado, usuario y comentario opcional.
- Registro automático de fecha y hora de cada actualización.
- Adjuntos de imágenes por actualización.
- Historial persistido en `localStorage` del navegador.

## Ejecutar en local
```bash
python3 -m http.server 8000
```
Abre `http://localhost:8000` en el navegador.
